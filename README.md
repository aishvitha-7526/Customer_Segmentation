# Customer Segmentation Using K-Means Clustering-CITS2755

## Project Overview
Customer Segmentation is a Machine Learning project that groups customers into different categories based on their spending habits and income. This helps businesses understand customer behavior and create effective marketing strategies.

## Objective
The main objective of this project is to identify similar groups of customers using the K-Means Clustering algorithm.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Methodology
1. Collect customer data.
2. Select important features such as Annual Income and Spending Score.
3. Apply the Elbow Method to find the optimal number of clusters.
4. Use K-Means Clustering to segment customers.
5. Visualize the customer groups.

## Results
- Customers are divided into different clusters.
- Each cluster represents a unique customer segment.
- The results can help businesses improve customer targeting and marketing decisions.

## Applications
- Customer Relationship Management
- Targeted Marketing
- Product Recommendations
- Business Analytics

## Conclusion
This project demonstrates how K-Means Clustering can be used to analyze customer behavior and identify meaningful customer segments, helping businesses make data-driven decisions.
